StrengthFuel PWA

Files:
- index.html
- styles.css
- app.js
- manifest.json
- sw.js
- icon.svg

How to use on iPhone:
1. Put these files on any static website host (for example GitHub Pages, Netlify, Cloudflare Pages, or similar).
2. Open the published website in Safari on your iPhone.
3. Tap Share -> Add to Home Screen.
4. Open StrengthFuel from your Home Screen like a normal app.

The app stores your data locally on the device using localStorage.
